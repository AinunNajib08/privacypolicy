🧩 Official Game Privacy Policy

Kebijakan Privasi / Privacy Policy

Aplikasi: Block Blast: Combo Puzzle • Package: com.blockblast.game.block_game • Pengembang: Nadirah Labs • Terakhir Diperbarui: Oktober 2026

1. Pendahuluan

Selamat datang di Block Blast: Combo Puzzle ("Aplikasi", "Game", atau "Kami"), game puzzle balok offline yang dikembangkan dan dikelola oleh Nadirah Labs. Kami sangat menghargai privasi Anda dan berkomitmen penuh untuk melindungi informasi pribadi para pemain.

Kebijakan Privasi ini menjelaskan bagaimana Kami mengelola data saat Anda mengunduh, menginstal, dan memainkan Block Blast: Combo Puzzle melalui platform Google Play Store.

Komitmen Utama: Block Blast: Combo Puzzle dirancang sebagai game puzzle kasual yang 100% offline. Kami tidak mengumpulkan, tidak menjual, dan tidak membagikan data identitas pribadi Anda kepada pihak mana pun. Tidak ada registrasi akun atau login yang dibutuhkan untuk memainkan game ini.

2. Informasi yang Disimpan di Perangkat (Lokal)

Untuk memastikan game berjalan lancar dan menyimpan pencapaian rekor Anda, game ini hanya menyimpan data secara lokal pada perangkat Anda menggunakan standar SharedPreferences:

  • Skor Tertinggi & Skor Saat Ini: Rekor nilai tertinggi (High Score) yang Anda capai saat memecahkan balok.
  • Pengaturan Preferensi Suara: Status on/off untuk Efek Suara (SFX), Musik Latar (BGM), dan Getaran (Haptic Feedback).
  • Status Tutorial: Penanda apakah tutorial interaktif awal telah diselesaikan.

Seluruh data di atas disimpan secara eksklusif di memori lokal ponsel Anda dan tidak pernah dikirimkan atau diunggah ke server eksternal mana pun.

3. Layanan Pihak Ketiga & Jaringan Iklan

Game ini adalah aplikasi yang dapat dimainkan sepenuhnya secara Offline tanpa koneksi internet.

Komponen Status Keterangan
Pelacakan Pengguna (Tracking) Tidak Ada (None) Kami tidak menggunakan tracker analitik pihak ketiga yang memonitor aktivitas pengguna di luar aplikasi.
Pengumpulan Lokasi (GPS) Tidak Ada (None) Game tidak meminta maupun mengakses izin lokasi perangkat Anda.
Jaringan Iklan Pihak Ketiga Bebas Iklan Pelacak Versi game ini tidak mengumpulkan data pribadi untuk tujuan penargetan iklan.

4. Privasi Anak-Anak (Children's Privacy / COPPA)

Game Block Blast: Combo Puzzle dirancang ramah keluarga dan aman untuk dinikmati oleh semua kelompok usia (*Family-Friendly & All Ages*).

  • Kami secara sadar tidak mengumpulkan informasi identitas pribadi (PII) dari anak-anak maupun orang dewasa.
  • Aplikasi ini sepenuhnya mematuhi regulasi Children's Online Privacy Protection Act (COPPA) dan Kebijakan Keluarga Google Play.

5. Hak Pengguna & Penghapusan Data

Karena seluruh data disimpan secara lokal pada perangkat Anda, Anda memiliki kendali penuh:

  • Menghapus Data Game: Anda dapat mereset seluruh skor dan pengaturan kapan saja melalui menu pengaturan ponsel: Pengaturan > Aplikasi > Block Blast > Penyimpanan > Hapus Data.
  • Uninstall: Menghapus aplikasi dari ponsel akan otomatis menghapus seluruh data lokal yang tersimpan secara permanen.

6. Keamanan Data (Data Security)

Keamanan informasi Anda adalah prioritas kami. Karena game tidak mentransmisikan data pribadi melalui internet, risiko kebocoran data pribadi Anda dapat dihindari secara mendasar (*safe by design*). Data pengaturan lokal dilindungi oleh sistem sandbox keamanan resmi sistem operasi Android.

7. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini sewaktu-waktu seiring pembaruan fitur aplikasi. Setiap perubahan akan diperbarui langsung pada halaman ini secara transparan beserta tanggal pembaruan terbaru di bagian atas.
